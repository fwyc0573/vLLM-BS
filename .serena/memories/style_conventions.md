# vLLM Style Conventions

## Formatting and Linting
- Python formatting: `yapf`
- Linting: `ruff`
- Import sorting: `isort`
- C++/CUDA formatting: `clang-format`
- Spelling checks: `typos`

## Enforcement
- Uses `pre-commit` hooks defined in `.pre-commit-config.yaml`.
- Run hooks locally via `pre-commit`.
