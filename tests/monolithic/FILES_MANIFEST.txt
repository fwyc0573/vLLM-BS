# MLP Predictor 误差分析工具集 - 文件清单
# 生成日期: 2025-12-16

## 核心脚本 (Python)

1. trace_mlp_error.py (7.6K)
   - 功能: 从单个 PyTorch profiler trace 拆分 PREFILL/DECODE，计算 MLP op 误差
   - 用法: python trace_mlp_error.py --trace <trace.json.gz> [--pred-json preds.json] [--csv-out out.csv]
   - 输出: 表格 (stdout) + 可选 CSV
   - 依赖: Python 3.9+, no external deps (json, gzip, dataclasses built-in)

2. batch_calibrate_mlp.py (4.6K)
   - 功能: 批量处理多个 traces，聚合误差统计
   - 用法: python batch_calibrate_mlp.py [--trace-dir profiles] [--pred-json preds.json] [--output-csv out.csv]
   - 输出: 聚合表格 + TOP-5 worst cases + CSV
   - 依赖: pandas, subprocess (pandas 需单独 pip install)

### DECODE Phase (M=8)
- post_attention_layernorm: +526.02% (严重 overpredict) ← 需要修复！
- mlp_act: +55.17% (适度高估)
- mlp_up_proj: +1.14% (准确) ✓

### 推荐修复方向
1. 检查 predictor 中 mlp_up_proj 是否用了正确的 output 维度 (2*intermediate_size vs intermediate_size)
2. 为 LayerNorm 在小 M 时添加 overhead 项（而不是简单线性外推）
3. 用多个配置重新采样和训练
